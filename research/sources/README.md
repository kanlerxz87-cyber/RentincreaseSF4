# Research / sources directory

Owned by T02 (`arena-73f5f1a2`). These are internal research notes; the public site renders the same official links from `data/sources.json` and `pages/sources.html`.

- `official_sources.md` — exact quotes, data and fetch chunk for each official source.
- `irregularities.md` — every source-quality flag, stale snippet, 404, example conflict, metadata mismatch and unparsed file; all `needs review`.
- `unverified.md` — every field left blank on the public site with official manual-review links.
- `method.md` — how sources were discovered, fetched, cross-checked and flagged.

Root-level `SOURCES.md` is the concise source ledger. `research/case_facts.md`, `research/calculations.md` and `research/flags.md` belong to T03 and are deliberately outside this directory's claimed scope.
